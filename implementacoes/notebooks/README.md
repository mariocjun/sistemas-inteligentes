# Notebooks — Implementações Práticas

Notebooks Jupyter cobrindo os 5 blocos da disciplina ICSI30, baseados na biblioteca AIMA (Artificial Intelligence: A Modern Approach).

## Blocos cobertos

| Notebook | Bloco | Tópicos |
|----------|-------|---------|
| `01_Agentes_Ambientes.ipynb` | 1 | Agentes reativos e reflexivos, ambientes PEAS |
| `01_aima_search_basics.ipynb` | 2 | Busca em profundidade, largura, custo uniforme |
| `02_aima_genetic_algorithm.ipynb` | 2 | Algoritmos genéticos, busca por população |
| `03_aima_minimax.ipynb` | 2 | Minimax, busca adversarial, jogos |
| `04_Aprendizagem_Arvores.ipynb` | 4 | Árvores de decisão, ID3, Random Forest |
| `05_Redes_Neurais.ipynb` | 5 | Perceptrons, backpropagation, redes convolucionais |

## Uso

1. **Requisitos**: Python 3.8+, Jupyter, bibliotecas AIMA
2. **Executar**: Abrir no Jupyter Notebook ou Google Colab
3. **Modificar**: Notebooks são templates — adapte para sua máquina local
