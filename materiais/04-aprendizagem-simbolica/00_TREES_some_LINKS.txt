HYPERPARAMETERS
---------------
1-COST FUNCTION: method used to identify the best split 
           in each tree — gini impurity, feature importance, etc. 

2-MAX DEPTH: how far from the root node can each tree grow. 

3-MINIMUM SAMPLES FOR A SPLIT:  number of records that must be 
           in each node to proceed with another split

4-NUMBER OF ESTIMATORS: how many trees are in the forest. 

5-MAX FEATURES: how many features are available at each split 
           (common default is the square root of the 
            total number of features)
